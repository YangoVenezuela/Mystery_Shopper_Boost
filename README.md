# GitHub Pages

Sube `index.html` y `yango_logo.png` a la raíz del repositorio. En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch**, `main` y `/ (root)`.

Esta versión funciona sin Python: lee la pestaña pública `Questions` mediante Google Visualization y filtra los viajes en el navegador.

La contraseña `Boost2026` está dentro de `index.html`; es una barrera visual, no seguridad real. Cualquier persona puede verla o saltarla inspeccionando el código.

GitHub Pages no puede escribir directamente en Google Drive. El botón abre la carpeta `Boost`; el usuario debe subir allí el archivo y utilizar el nombre generado por la página.

Los datos de `Questions`, incluidos correos, rutas y precios, quedan accesibles públicamente a través de Google Sheets. Los permisos de facturas y comprobantes dependen de la carpeta de Drive.
